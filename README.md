# 🧮 Calculator

A clean, browser-based calculator built with vanilla JavaScript — no libraries, no frameworks.

## ✨ Features

- All basic operations: addition, subtraction, multiplication, division, modulo
- Backspace button (`<-`) to delete the last character
- Clear button (`Clr`) to reset the display
- Decimal point support
- Error handling for invalid expressions (shows `Error` instead of crashing)
- Buttons dynamically generated via JavaScript loop

## 🛠️ Tech Stack

`HTML5` `CSS3` `Vanilla JavaScript`

## 🚀 How to Run

No installation needed — just open in your browser:

```bash
git clone https://github.com/charat-toomer/Calculator.git
cd Calculator
open index.html
```
